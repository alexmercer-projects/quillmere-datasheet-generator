Validation

What gets checked

The generator checks the spreadsheet first, then measures the actual print layout in Chrome.

01 / Identity

Required fields and SKUs

Finds empty cells and flags every row that shares a duplicate SKU.

02 / Measurements

Numbers and units

Checks ranges, expects millimetres, kilograms and Celsius, and recalculates efficacy within 2%.

03 / Content

Images, finishes and length

Checks local image files, known finish names and character limits for each text field.

04 / Print

Text fit and page count

Measures marked text boxes after fonts load. Poppler confirms the PDF has exactly one page.
